# Deploy to Vercel

1. Import `fernandatrevi/brainscan-ai` at https://vercel.com/new.
2. Select the Next.js framework preset and keep the repository root as the root directory.
3. Deploy using the Hobby plan within its usage limits.
4. Open the generated `*.vercel.app` subdomain.
5. Verify navigation, case selection, mock results and chart responsiveness.

No environment variables are required for the demo.
